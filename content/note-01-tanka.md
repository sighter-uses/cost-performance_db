# 蒸留酒2,466本を「純アルコール20gあたりいくらか」で並べたら、選び方が変わった

※本記事は楽天アフィリエイトプログラムを利用した広告を含みます。
※20歳未満の方の飲酒は法律で禁じられています。

---

酒の値段は比べにくいです。700mlのウイスキーが1,125円、1.8Lの焼酎が3,828円。度数も40度と25度で違う。どちらが得なのか、店頭で暗算できる人はいないと思います。

なので、楽天市場の蒸留酒2,466本を全部同じ物差しに載せてみました。**純アルコール20gあたり何円か**、という一本の軸です。

20gというのは日本酒1合、ビール中瓶1本にほぼ相当する量で、厚生労働省が2024年のガイドラインで基準にしている単位でもあります。計算式は単純です。

```
純アルコール量(g) = 容量(ml) × 度数 ÷ 100 × 0.8
20g単価 = 価格 ÷ 純アルコール量 × 20
```

商品名と説明文から度数と容量を機械的に読み取って計算しました。読み取れなかったものは載せていません。

やってみたら、思っていたのと違う結果がいくつも出ました。

---

## 種別で5倍違う

まず全体像です。1本1.8L以下の家庭用サイズに絞って、種別ごとの中央値を出しました。

| 種別 | 20g単価の中央値 |
|---|---:|
| ウォッカ | 148.5円 |
| 焼酎 | 212.7円 |
| ジン | 313.4円 |
| ラム | 336.1円 |
| テキーラ | 570.8円 |
| ウイスキー | 627.6円 |
| ブランデー | 774.0円 |

**ウォッカとブランデーで5.2倍**。同じ量のアルコールを摂るのに、種別を変えるだけでこれだけ変わります。

とはいえ「じゃあウォッカを飲もう」という話ではありません。飲みたいものを飲むべきです。ただ、**自分がどのくらいのコストを払っているかは知っておいていい**と思いました。

---

## 「高い酒ほど評価が高い」は成立しなかった

これが一番意外でした。

レビュー10件以上の522本について、20g単価と評点の相関を取りました。結果は **r = 0.006**。ゼロです。

| 20g単価 | 平均評点 |
|---|---:|
| 〜80円 | 4.74 |
| 80〜150円 | 4.71 |
| 150〜300円 | 4.69 |
| 300〜800円 | 4.70 |
| 800円〜 | 4.72 |

**10倍の価格差があっても、評点は0.05しか動きません。**

ただし正直に書いておくと、この数字はそのまま「高い酒と安い酒は同じくらい美味い」を意味しません。楽天のレビューは評点が高いほうに偏っていて、**4.5〜5.0の範囲に90%が入ります**。物差しとしての目盛りが粗いので、差が出にくいのは当然でもあります。

それでも、**価格を美味しさの代理指標に使うのは無理がある**とは言えると思います。少なくとも「高いから間違いない」という選び方の根拠にはならない。

---

## 単価を決めているのは、種別より容量だった

もう一つ、はっきり出た関係があります。

| 1本あたり容量 | 20g単価の中央値 |
|---|---:|
| 〜300ml | 767.4円 |
| 300〜500ml | 536.0円 |
| 500〜750ml | 392.9円 |
| 750〜1000ml | 232.4円 |
| 1000〜1800ml | 137.4円 |
| 1800ml〜 | 85.0円 |

**9倍の差**です。相関係数も −0.391 と、種別よりよほど強く効いています。

さらにセット買い（同じ商品の複数本まとめ）は、単品に対して**中央値で51.5%安い**。半額です。

つまり単価だけを見るなら、答えは身も蓋もなくて「**大きいものをまとめて買え**」になります。置き場所と飲み切れるかは別問題ですが。

## 全2,466本を並べたサイトを作りました

この記事で出した数字は、全部ここから抜いたものです。

**[蒸留酒 単価一覧](https://cost-performance-db.inspecting.workers.dev/)**

記事に書ききれない部分がいくつかあります。

- **ポイント還元込みの実質価格が出せます。** 還元率はSPUの状況で人によって違うので、スライダーで自分の値を入れると全件が並び替わります。1%と15%では上位20件のうち8件の順位が入れ替わります
- **商品ごとの期間限定ポイント倍率が反映されます。** 24時間以内に終了するものはAPIが返さないので、記事には書けない情報です
- 銘柄名での検索、最大4銘柄の横並び比較ができます

無料です。会員登録もありません。

## これから、面白いものを拾っていきます

この記事は全体像の話でした。ただ、2,466本もあると**平均や中央値からこぼれる変な商品**が必ず出てきます。今回紹介した「ウイスキーなのに焼酎より安い4Lボトル」や「度数が高すぎて単価が下がる75.5度のラム」がまさにそれです。

そしてこのデータは更新され続けます。価格は動くし、ポイント倍率は24時間単位で変わるし、新しい銘柄も入ってきます。つまり**放っておいても面白い商品が湧いてくる**わけで、それを不定期に拾って紹介していこうと思います。

たとえばこういうものです。

- 期間限定でポイント倍率が跳ねていて、実質価格が一時的に他とかけ離れている商品
- 種別の相場から明らかに外れているのに、評価も落ちていない商品
- 容量違いで単価が倍以上ちがう、同じ銘柄

どれも**その時のデータを見ないと分からない**ものなので、書けるときに書きます。等間隔では出しません。

「安く酔いたい」でも「コスパよく美味いものが飲みたい」でも、判断に使える数字を置いておくのが目的です。よかったらフォローしておいてください。
