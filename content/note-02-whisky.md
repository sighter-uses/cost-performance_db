# ウイスキー4Lは本当に安いのか — 370本の単価を全部計算したら、容量だけで19倍ちがった

※本記事は楽天アフィリエイトプログラムを利用した広告を含みます。
※20歳未満の者の飲酒は法律で禁じられています。

---

前回、蒸留酒2,466本を「純アルコール20gあたりいくらか」で並べた話を書きました。今回はそのうちウイスキーだけを取り出して、**370本**の中身を見ていきます。

先に結論を書きます。**ウイスキーの単価を決めているのは、銘柄でも産地でも熟成年数でもなく、容量でした。**

---

## ウイスキーは蒸留酒のなかで2番目に高い

純アルコール20g（日本酒1合、ビール中瓶1本にあたる量）あたりの価格で、種別ごとの中央値を並べるとこうなります。

```
ウォッカ     148円
焼酎        199円
ジン        314円
ラム酒      333円
テキーラ    567円
ウイスキー   579円
ブランデー   687円
```

ウイスキーは579円。ウォッカの約3.9倍です。「ウイスキーは高い」という感覚は、数字としては正しいことになります。

**ただしこれは中央値の話であって、ウイスキーという種別が高いという話ではありません。**

---

## 容量帯で切ると、19倍の差が出る

同じウイスキー370本を、容量帯ごとに中央値を出し直します。

```
300ml以下      1,427円   （14本）
300〜750ml       644円  （310本）
750〜1,800ml     287円   （21本）
1.8〜3L          112円    （5本）
3L以上            74円   （20本）
```

**300ml以下と3L以上で19.3倍。** 種別間の最大差（ウォッカ148円 対 ブランデー687円）が4.6倍ですから、**容量による差のほうが4倍以上大きい**ことになります。

掲載370本のうち310本が300〜750mlに集中しているので、中央値579円というのは実質「700mlボトルの相場」を指しています。ウイスキーが高く見えるのは、**売られているサイズが偏っているから**です。

---

370本のうち最も単価が安かったのはこれでした。

**54.9円というのは、焼酎の中央値199円すら下回っています。** 「安く酔うなら焼酎」という通念は、この1本の前では成立しません。

## それは「何日で飲む酒」なのか

ここが今回いちばん書きたかったところです。

単価だけ見ると4L×4本が圧倒的です。でもこの16Lに含まれる純アルコールは**4,736g**あります。

厚生労働省の飲酒ガイドライン（2024年）は、生活習慣病のリスクを高める量として**男性40g／日、女性20g／日**という目安を示しています。この量を毎日飲み続けたとして、消費にかかる日数はこうなります。

```
4L × 4本（16L）  純アルコール4,736g  →  118日 / 237日
4L × 1本         純アルコール1,184g  →   30日 /  59日
1.8L 1本           純アルコール533g  →   13日 /  27日
700ml 1本          純アルコール224g  →    6日 /  11日
                              （左が40g/日、右が20g/日の場合）
```

**4L×4本は、リスクを高める上限ペースで飲み続けても4〜8ヶ月かかる量です。** 単価表の1位ではありますが、これは「1回の買い物で半年分の酒を家に置く」という選択でもあります。

大容量が単価で有利なのは事実です。ただ**単価が下がるのは総量が増えるからであって、支出が減るわけではありません。** 4L×4本は12,995円、700ml1本は1,000円台です。

安く飲みたいという動機と、たくさん買うという行為は、同じものではありません。**単価の表を見るときは、右端の総額も一緒に見てください。**

## 大容量を置けない人向けの現実的な答え

4Lペットは置き場所を選びますし、注ぐのも大変です。700mlで探すとどうなるか。

**ホワイトホース ファインオールド 700ml**
40度・1,125円・★4.80（85件）
→ **20gあたり100.4円**（370本中、安い側から5.9%）

[楽天で見る](https://hb.afl.rakuten.co.jp/hgc/g00q8iso.4zioha3d.g00q8iso.4zioi06f/?pc=https%3A%2F%2Fitem.rakuten.co.jp%2Fledled%2F3-white-horse-fine-old-p%2F&m=http%3A%2F%2Fm.rakuten.co.jp%2Fledled%2Fi%2F10003969%2F&rafcid=wsc_i_is_e7c2ee1c-d168-4943-8d3a-a0139c1b64f9)

**4Lを買わなくても、中央値の1/5以下で買えるものはあります。** 大容量が最安なのは事実ですが、大容量でなければ安くならないというのは誤りです。

もうひとつ、1.8Lという選択肢もあります。

**合同酒精 香薫 1.8L**
37度・1,799円・★5.0（2件）
→ **20gあたり67.5円**（安い側から2.7%）

[楽天で見る](https://hb.afl.rakuten.co.jp/hgc/g00rryxo.4zioh2f0.g00rryxo.4zioi23b/?pc=https%3A%2F%2Fitem.rakuten.co.jp%2Fliquor-boss%2F22484b%2F&m=http%3A%2F%2Fm.rakuten.co.jp%2Fliquor-boss%2Fi%2F10008034%2F&rafcid=wsc_i_is_e7c2ee1c-d168-4943-8d3a-a0139c1b64f9)

1,799円で純アルコール533g。**4Lに迫る単価でありながら、総額は700ml2本より安く済みます**（上のホワイトホース2本で2,250円）。レビューが2件しかないのは弱点なので、そこは割り引いて見てください。

## おまけ：角瓶は実は「安い側」だった

誰もが知っているサントリー角瓶。700mlで1,672円、20gあたり**149.3円**です。

これが370本中どのあたりかというと、**安いほうから11.9%**。中央値579円の約4分の1です。

**サントリー ウイスキー 角瓶 700ml**
40度・1,672円・★4.60（154件）

[楽天で見る](https://hb.afl.rakuten.co.jp/hgc/g00q8iso.4zioha3d.g00q8iso.4zioi06f/?pc=https%3A%2F%2Fitem.rakuten.co.jp%2Fledled%2F2-kakubin-700%2F&m=http%3A%2F%2Fm.rakuten.co.jp%2Fledled%2Fi%2F10001208%2F&rafcid=wsc_i_is_e7c2ee1c-d168-4943-8d3a-a0139c1b64f9)

「角瓶は普通の値段」という感覚があるとしたら、それは**700mlという売れ筋サイズの中で普通**という意味です。

370本のうち310本が300〜750mlに入っていて、その帯の中央値は644円。**つまりウイスキーの中央値579円は、ほぼそのまま「700mlボトルの相場」です。** そしてその帯には熟成年数のついた高価格帯が大量に入っている。角瓶が安く見えるのは、同じ700mlの中に何千円のボトルが並んでいるからです。

---

## まとめ

- ウイスキーの20g単価の中央値は**579円**（370本、2026年9月1日時点）
- 容量帯で切ると**300ml以下1,427円 対 3L以上74円で19.3倍**。種別間の差(4.6倍)より大きい
- 最安は4L×4本で**54.9円**。焼酎の中央値199円を下回る
- ただし4L×4本は**純アルコール4,736g**。ガイドラインの上限ペースでも4〜8ヶ月分
- 700mlでも**100.4円**の選択肢はある。大容量でなければ安くならないわけではない
- 角瓶は**安いほうから11.9%**
