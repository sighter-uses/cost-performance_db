# 集めた知識と、そこから決まること

2026-09-04 調査。この分野は情報の質が極端に低く、情報商材への誘導と
数字のない一般論が大半を占める。**実測値・再現手順のあるものだけを採用**し、
根拠のない主張は載せていない。「調べたが使えなかった」ものも記録する ——
同じ軸をまた調べ直さないため。

---

## 1. 前提が変わっている — AI Overviews

| 事実 | 出典の性質 |
|---|---|
| 2026年3月時点で**全検索クエリの約48%**にAI Overviewsが表示（2025年12月は34.5%） | 計測値 |
| 自然検索のクリック率が**約6割減** | 計測値 |
| 影響が最も大きいのは**情報収集系クエリ**（「〇〇とは」「〇〇 方法」） | 分析 |
| **上位表示されてもAI要約から外れれば流入は減り、中位以下でも要約内に引用されれば増える** | 分析 |

順位を追う従来のSEOは、前提として壊れている。代わりに追うべき指標は3つ。

1. **AIの回答内で引用されている割合**
2. **指名検索の数**
3. **第三者からの言及（サイテーション）**

我々が最初に立てた「AI Overviews耐性のあるクエリは、ローカル・最新ニュース・指名検索の3つ」
という整理は、この文脈で **指名検索** が残ることと一致している。

## 2. AIが情報源を選ぶ6つの基準

これが今回いちばん重要な収穫。**満たすべき条件が具体的**で、しかも
一般的なアフィリエイトブログには満たせず、**我々には満たせる**。

| 基準 | 中身 |
|---|---|
| **到達可能性** | AIがページをクロール・読み取れる状態か |
| **関連性** | ユーザーの質問と回答内容の一致度 |
| **根拠性** | 主張を裏付けるデータ・出典が明示されているか |
| **信頼性** | 著者・組織の専門性が示されているか（E-E-A-T） |
| **鮮度** | 情報の最新性と定期更新の有無 |
| **使いやすさ** | AI回答にそのまま引用できる形式で書かれているか |

### 決定的な一文

> **独自調査によって「まだ世の中にない数字」をゼロから作り出すことが、AIにとっての新しい引用元になる**

これは我々のサイトの説明そのものである。純アルコール20g単価は世の中に存在しない数字で、
2,466件を集計して作っている。**AI Overviewsに殺される側ではなく、引用される側に回れる**
数少ない形をたまたま作っていた。

### データの示し方（必須3項目）

- **n数** — 母数が明示されていないデータは引用適性が大きく下がる
- **調査期間** — 「〇〇年〇月〇日〜〇月〇日実施」と具体的に
- **対象の定義** — 何を対象としたかを限定して明記

**最低基準 n=100 / 引用対象レベル n=300以上。**
我々は全体2,466件、種別ごとでも309〜386件。**全ページで引用対象レベルを超えている。**

### ページ構造でやるべきこと

- 調査概要を**ボックス形式で独立したブロック**に
- 各セクションは**1データポイント×1テーマ**で完結
- 図表には alt とキャプション
- **Article / FAQPage スキーマ**を JSON-LD で
- sitemap.xml の `lastmod` を正確に

### やっても効果が薄いこと

- 装飾優先の複雑なグラフ
- 複数の発見を1セクションに詰め込む
- **著者情報の省略**
- 調査概要なしでデータだけ掲載
- 被引用の確認をせず放置する運用

なお**構造化データの実装は優先度が比較的低い**という指摘もあった。
一次情報とE-E-A-Tのほうが効くという整理。

## 3. 我々のサイトの現状（実測）

| 基準 | 項目 | 状態 |
|---|---|---|
| 到達可能性 | SSRで商品名がHTMLに出る | **満たす** |
| 到達可能性 | sitemap 宣言 | **満たす** |
| 根拠性 | 計算式の開示 | **満たす** |
| 根拠性 | n数の明示 | **満たす** |
| 根拠性 | 調査概要が独立ブロック | **未対応** |
| 信頼性 | 著者情報 | **未対応** |
| 鮮度 | 取得日の明示 | **満たす** |
| 鮮度 | 調査期間の形式 | **未対応** |
| 使いやすさ | Article スキーマ | **未対応** |
| 使いやすさ | FAQPage スキーマ | **未対応** |

**埋めるべき穴は4つ。** どれも一度直せば終わる種類のもので、
週5時間の制約に合っている（記事を毎回書くのとは性質が違う）。

優先順:
1. **著者情報** — 「やっても効果が薄いこと」に名指しで挙がっている欠落
2. **調査概要ブロック** — フッターに散らばっている情報を独立させる
3. **調査期間の表記** — 「取得日」から「〇月〇日〜〇月〇日」形式へ
4. **Article / FAQPage スキーマ** — 優先度は低いとされるが安い

## 4. サイテーション（第三者からの言及）

- サイテーションは**リンクなしの言及**。被リンクとは別物で、役割は知名度・ブランド認知
- 独自の調査・統計データはプレスリリースやレポートとして公開すると自然な被リンクを生む
- **ただしプレスリリース経由の被リンクはほとんど nofollow**

これも我々の形と噛み合う。データを持っていることが、言及される理由になる。

## 5. 調べたが使えなかったもの

**同じ軸をまた調べないための記録。**

| 軸 | 結果 |
|---|---|
| X（Twitter）フォロワー0からの立ち上げ | 「プロフィールを整える」「毎日投稿」「交流する」レベルの一般論のみ。再現手順として使える証拠なし |
| はてなブックマーク ホットエントリー | 掲載基準は非公開。「1時間以内に3〜5ブックマークで新着」という伝聞のみ。同一IPからのブクマはホットエントリー入りしないという報告あり（＝自演は効かない） |
| アフィリエイトの失敗パターン | 「継続できない」「ジャンル選定ミス」等の一般論。ただし1つだけ有用 → **ノウハウコレクターになること** が失敗要因に挙がっている |
| アフィリエイト初期集客の定石 | 「テーマ決定→キーワード収集→検索意図確認→執筆」という手順論。目新しさはないが、**キーワードから逆算する順序**は我々がやっていない |

## 6. この調査から導かれる方針

**主戦場を「順位」から「引用」に置き換える。**

一般的なアフィリエイトブログは、AI Overviewsに要約されて流入を失う側にいる。
我々は一次データを持っているので、**引用される側**に回れる。しかもその条件は
明文化されていて、我々は6基準中6項目を満たしており、残り4項目も一度の作業で埋まる。

これは週5時間の制約とも噛み合う。**記事を毎回書くのは介入が毎回発生するが、
引用される条件を満たすのは一度で終わる。**

ただし正直に書いておくと：

- **引用されるまでの期間は誰も明示していない。** 数ヶ月かかると見るべき
- **引用されても収益に直結するとは限らない。** AIの回答内で名前が出ても、
  クリックされなければアフィリエイト収益はゼロ。ここは検証されていない
- 上の調査は「引用されやすくなる条件」であって「引用される保証」ではない

### やめること

- **ノウハウの追加収集**。この調査で得たものを実行に移す段階で、
  さらに調べるのは失敗パターンとして名指しされている行動そのもの
- X・はてブの攻略。再現手順の証拠がない軸に週5時間を割く根拠がない

### 順序

1. 6基準の穴4つを埋める（一度で終わる、私が全部やる）
2. PLAN.md の記事を書き始める（指名検索とサイテーションの土台）
3. 1ヶ月後、Search Console で「引用されているか」を確認して方針を見直す
