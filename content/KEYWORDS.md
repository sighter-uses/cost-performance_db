# 検索語の実測 — 何と打たれているか

2026-09-09 取得。Google サジェスト（`suggestqueries.google.com`, `hl=ja&ie=utf8&oe=utf8`）。
**推測ではなく、実際に補完候補として返ってくる語だけを載せる。**

KNOWLEDGE.md で「キーワードから逆算する順序を我々はやっていない」と未対応にしていた工程。
記事を書く前にここへ戻ること。

---

## 1. 結論 — 我々の語と、世の中の語がずれている

| | 我々が使っている語 | 実際に打たれている語 |
|---|---|---|
| 中心語 | 単価 / 純アルコール20g | **コスパ / コスパ最強** |
| 形式 | 一覧 | **ランキング** |
| 価格 | 単価 | **安い / 最安値** |
| 量 | 容量 | **大容量** |

**「コスパ最強」と「ランキング」は全種別で共通して出る。**
ウイスキー・焼酎・ジン・テキーラ・ブランデー・ウォッカ・酒、どれにも付く。
我々のサイトはまさにコスパのランキングなのに、**その語を1つも使っていなかった。**

### 「純アルコール」は入口の語にならない

`純アルコール量` のサジェストは **計算 / とは / 目安 / 1日 / 40g毎日 / 100g毎日**。
**全部が健康・適量の文脈で、価格の文脈が1つもない。**
この語で来る人は「飲みすぎか知りたい人」であって「安い酒を探している人」ではない。

さらに悪いことに、`酒 20g` は **「酒 20g は何cc」「料理 酒 20g」** ——
**料理酒の分量検索に完全に食われている。**

→ **「純アルコール20g」は看板（入口）ではなく、根拠（中身）に置く。**
入口の語は「コスパ」「ランキング」「安い」にする。

### 「蒸留酒」単体も入口にならない

サジェストは **とは / 醸造酒との違い / 種類 / 英語 / 作り方 / 名前一覧**。
**全部が用語解説クエリで、購買意図がない。**
サイト名として使うのは構わないが、この語で流入を期待してはいけない。

## 2. 記事の裏づけ（PLAN.md との対応）

### 記事01（ウイスキー・大容量）→ **需要あり。優先度そのまま**

実在する検索語:
- `ウイスキー 4l` / `ウイスキー 4l 最安値` / `ウイスキー 4l おすすめ`
- `ウイスキー コスパ 4l`
- `ウイスキー 大容量` + **安い / ランキング / コスパ / おすすめ** が全部付く
- `ウイスキー 安い 大容量`

**「4Lボトルが中央値の1/10.5」という記事01の主題は、実在する検索需要にそのまま当たる。**

おまけの発見: `ウイスキー 4l 何日` / `ウイスキー 4l アル中`。
**大容量を買う人は消費ペースを気にしている。**
純アルコール量の話に自然に接続できる ——「4Lは純アルコール何g分か」は、
彼らが知りたいことであって、我々だけが計算できることでもある。

### 記事14（1杯いくらか）→ **需要あり**

- `ウイスキー 1杯 値段` / `1杯 アルコール量` / `1杯 何ml`
- `山崎 ウイスキー 1杯 値段` / `響 ウイスキー 1杯`
- `ハイボール 一杯 いくら` / `一杯 アルコール量` / `一杯 カロリー`

**銘柄名 + 1杯 + 値段**で検索されている。我々のデータで正確に答えられる形。

### 記事04（ラム）→ **語を変えないと当たらない**

`ラム コスパ` のサジェストは **ラムダッシュ（シェーバー）とラム肉に食われている。**
ラム酒は「ラム 酒 コスパ」「ホワイト ラム コスパ」でしか出てこない。

→ **ラムを扱うときは必ず「ラム酒」と書く。** ページタイトルも同様。

## 3. サイトに反映したこと（2026-09-09）

`<title>` と `<meta description>` に、実測された語を入れた。
**h1 とサイト名「蒸留酒 単価一覧」は変更していない** —— これは決めた識別子なので動かさない。
検索に向く面と、名乗りの面を分けて扱う。

- title に **コスパ / ランキング** を入れる
- ラムのページだけ **「ラム酒」** で表記する（上記の衝突回避）
- 中央値は title に残す（引用されたときに数字ごと引かれる）

---

## 4. やらないと決めたこと

**「コスパ最強ランキング」を正面から取りに行かない。**
被リンクを積んだアフィリエイトサイトが並んでいる語で、勝てる見込みがない。
語彙を合わせるのは**関連性（6基準の1つ）を満たすため**であって、
head キーワードで殴り合うためではない。

我々の勝ち筋は KNOWLEDGE.md のとおり **引用されること**。
語彙を合わせるのは、引用されるときに「何の話か」が一致していないと選ばれないから。
