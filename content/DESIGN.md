# 設計指針 — ディーター・ラムス「良いデザインの十箇条」の適用

2026-09-26 決定。**十箇条を額に飾らず、各条を「このサイトで何をするか／何をやめるか」に翻訳する。**
判断に迷ったら条番号に戻ること。守れているかを機械的に検査できる項目は、数値で書いてある。

---

## 前提：この刷新は、直前の方向を否定する

現行（2026-09-01 決定の「液相」）は、暗い地にギヨシェ紋・発光・粒状ノイズ・
アニメーションを重ねた装飾的な方向だった。**第5条と第10条に照らすと、これらは
データの役に立っていない。** 見た目の良し悪しの話ではなく、原則に照らして落ちる。

ただし**紋を消しはしない。** 全面の背景としてではなく、**16pxの識別子**として残す。
出自を捨てる必要はない ―― 出しゃばらせないだけでよい（第5条）。

---

## 第1条 革新的である

**このサイトの革新は視覚ではなく単位にある。** 「純アルコール20gあたりの価格」は
他所にない数字で、価格・度数・容量の3変数を1本の軸に畳んでいる。

→ **デザインの仕事は、この単位を発明することではなく、最短で理解させること。**
視覚的な新規性を追わない。追えば第7条（長持ち）と衝突する。

## 第2条 実用性を高める

このサイトの実用とは**比較**である。使われている機能は3つ。

1. 20g単価で並べる
2. 還元率を入れて実質価格に組み替える
3. 最大4銘柄を横に並べる

→ この3つを最短手数に置く。**それ以外の要素は、この3つの邪魔をしないことが条件。**

## 第3条 美しくある

**美は装飾からではなく、比率・整列・余白から出す。**

- 余白は4pxの倍数のみ（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64）。中間値を作らない
- 数値は**すべて右揃え・等幅数字**（`font-variant-numeric: tabular-nums`）。
  桁が揃わない一覧は、比較表として機能しない
- 文字サイズは6段階まで（12 / 13 / 15 / 18 / 24 / 32px）。増やさない

## 第4条 分かりやすくする

**「円/20g」は説明なしには意味が通らない。** これを説明する責任は本文ではなく画面にある。

- 単位の定義（20g＝日本酒1合＝ビール中瓶1本）を**1画面目の、数値の隣に**置く
- 各列の見出しを省略しない。アイコンだけで意味を担わせない
- 並び順が何であるかを常に画面に出す（「安い順」が効いているのかが常に分かる）

## 第5条 慎み深い

**廃止するもの:**

- 全面のギヨシェ紋（回転アニメーション含む）
- 発光レイヤー（`radial-gradient` + `blur`）2枚
- 粒状ノイズのオーバーレイ
- 行の立ち上がりアニメーション
- すりガラス（`backdrop-filter: blur`）

**残す動き:** 状態が変わったことを伝えるものだけ。押した／選んだ／絞り込んだの
フィードバックに限り、**120ms以内**。演出のための時間を取らない。

## 第6条 誠実である

**現行の暗い地＋琥珀＋箔押し風の紋は「高級酒のブランドサイト」に見える。**
中身は価格比較表であって、高級品を扱っているわけではない。**見た目が中身を偽っている。**

→ **明るい中性地にする。** 商品を良く見せる装置を持たない。
→ 除外した商品数・既知の限界を、今と同じく隠さず出し続ける（すでに実装済み）。
→ アフィリエイトであることの明示を、目立つ位置に置き続ける。

## 第7条 長く使える

**流行りの効果を使わない。** すりガラス、発光、粒状ノイズ、グラデーション、
大きな角丸は、いずれも時期の刻印が強い。

- 角丸は **0 または 2px** のみ
- 影は使わない。面の区別は**罫線1本**で行う
- 色数を増やさない（下記）

## 第8条 最後の細部まで首尾一貫している

**色は3つ＋1。**

```
地       #f7f6f4   わずかに温かい無彩色
文字     #1a1a1a   純黒にしない（にじみが強くなるため）
補助文字 #6b6660
罫線     #dcd8d2
強調     #b45309   ← 1色だけ。単価と、いま効いている操作にのみ使う
```

**評価（★）に色を与えない。** 位置とラベルで区別できるものに色を足すのは
第10条に反する。現行は琥珀＝価格／緑青＝評価の2色だったが、**1色に減らす。**

**書体は1つ。** Murecho（日本語・数字とも）。
現行の Fraunces（数値用の装飾セリフ）は**やめる** ―― 読ませたいのは数の大きさであって、
書体の表情ではない。等幅数字の指定を全数値に効かせる。

## 第9条 環境に配慮する

**ウェブでのこの条は、転送量である。** 現状は測定済みで、はっきり重い。

| | 現状 | 目標 |
|---|---:|---:|
| トップページHTML | 1,730 KB | **300 KB 以下** |
| OG画像 | 1,600 KB | **200 KB 以下** |
| 外部リクエスト | Google Fonts 2ドメイン | 削減を検討 |

主因は**全2,454件をJSONで各ページに埋め込んでいること。** 閲覧者の大半は
上位数十件しか見ないのに、毎回全件を送っている。

→ 初期表示分だけを埋め込み、残りは必要になってから取りに行く形に変える。
→ OG画像はPNGをやめる。

**これは第2条（実用）と衝突しない。** 検索と比較はブラウザ側で全件を持つ前提だったが、
全件データを別ファイルに分けて遅延取得すれば、機能は保ったまま初回の転送量が減る。

## 第10条 できる限り少なく

**「少なく、しかしより良く」。** 迷ったら消す。

削除の判断基準 ―― **その要素を消して、上の第2条の3機能が成立しなくなるか。**
成立するなら消す。「あったほうが賑やか」は理由にならない。

## 検査項目（実装後に機械で確認する）

```
□ トップページ 300KB以下
□ OG画像 200KB以下
□ 角丸は 0 または 2px のみ
□ box-shadow が0件
□ backdrop-filter が0件
□ 装飾用 @keyframes が0件（状態遷移120ms以内のものは可）
□ 色の定義が上の5色のみ
□ 書体ファミリ指定が1つ
□ すべての数値に tabular-nums が効いている
□ 余白の値が4の倍数のみ
```
