# note 記事の在庫 — 週2本 × 3ヶ月（24本）

書く段階で調査が要らないよう、**どのデータを使うか**まで先に決めてある。
ネタ切れは「その時に考える」方式だと必ず起きるので、在庫を先に積む。

規律は変わらない ―― **このデータがないと書けない記事だけ**。
一般論や体験談は書かない。他所で読めるものを書く理由がない。

各記事の必須要素:
- 冒頭にPR表記と20歳未満飲酒禁止
- 末尾に価格の時点注記と法定表示
- サイトへの導線（記事に書けないこと＝実質価格・期間限定倍率・検索・比較）
- ハッシュタグ8個（`#蒸留酒単価一覧` は毎回固定）

## 数字の定義（毎回ここに戻ること）

**中央値は全件ベース。** 家庭用サイズ（1本1.8L以下）で絞ってはいけない。
サイトの各ページが表示しているのが全件ベースの値なので、記事で絞った値を出すと
読者が突き合わせた瞬間に矛盾する。

差は小さくない ―― ブランデーは全件687円に対し家庭用774円で **87円ちがう**。
大容量品は単価が安いため、含めると中央値が下がる。

| 種別 | 全件（サイト表示・記事で使う） | 家庭用のみ（使わない） |
|---|---:|---:|
| ウォッカ | 148円 | 149円 |
| 焼酎 | 199円 | 213円 |
| ジン | 313円 | 313円 |
| ラム | 333円 | 336円 |
| ウイスキー | 567円 | 628円 |
| テキーラ | 567円 | 571円 |
| ブランデー | 687円 | 774円 |

家庭用サイズの話をする場合は「1本1.8L以下に絞ると」と明示する。

## 第1期（1〜8週目）— 今あるデータだけで書ける

### 01. ウイスキーは本当に高いのか — 380本の中央値と、その1/10で買える例外
**主張**: ウイスキーの中央値は567円/20g で全種別2位の高さ。だが4Lボトルは64.5円で、焼酎の中央値199円すら下回る。「種別が高い」は容量ひとつで崩れる。
**データ**: `/whisky/` の中央値・最安・上位20件。容量帯別の中央値。
**紹介**: 4Lケース品、700ml単品で最安級のもの、中央値付近の代表銘柄。

### 02. 焼酎の単価は蒸留酒で2番目に安い — 358本を並べて分かった構造
**主張**: 中央値199円はウォッカ148円に次ぐ安さ。理由は25度前後の1.8Lパックが主流だから。度数と容量の組み合わせが単価を決めている。
**データ**: `/shochu/` 全件。度数分布（25度に集中）、容量分布（1800mlに集中）。
**紹介**: 1.8Lパックのケース品上位、単品で買えるもの。

### 03. ジン386本 — 種類が最も多く、価格帯が最も広い
**主張**: 掲載数が全種別最多。クラフトジンの台頭で価格帯が64円〜数千円に広がっている。
**データ**: `/gin/` の単価分布のヒストグラム、最安と最高の開き。
**紹介**: 最安帯、評価4.5+かつ中央値以下（49件ある）から数本。

### 04. ラムの単価は「産地」ではなく「容量」で決まる
**主張**: 中央値333円。産地別の差より容量別の差のほうが大きい。
**データ**: `/rum/` 375件。容量帯別中央値と、産地語（ジャマイカ/キューバ等）を含む商品の単価比較。
**注意**: 産地の抽出は商品名からの推定になる。取れなければ容量の話に寄せる。

### 05. ウォッカが最も安い理由 — 中央値148円の内訳
**主張**: 全種別で最安。度数40度前後で大容量が多く、香味成分が少ない分だけ製造も単純。
**データ**: `/vodka/` 339件。度数分布、大容量品の比率。
**紹介**: 1.8Lペット、業務用サイズ、評価付きの上位。

### 06. テキーラは評価付き商品が最も少ない — 309本中69本
**主張**: 中央値567円と高い一方、レビュー10件以上が全種別で最少。日本での購買が薄い種別。
**データ**: `/tequila/` 309件。評価付き比率を他種別と比較。
**注意**: 「日本で人気がない」と断定しない。レビュー数は購買量の代理指標にすぎない。

### 07. ブランデーが最も高い — 中央値687円と、その理由
**主張**: 全種別で最高値。熟成年数を持つ商品が多く、少量のヴィンテージ品が中央値を押し上げる。
**データ**: `/brandy/` 319件。年数表記のある商品とない商品の単価差。

### 08. 「強い酒ほど安い」は半分だけ正しい
**主張**: 60度超の中央値は113円で全度数帯の最安。しかし41〜46度は516円で最も高い。度数と単価は単調な関係にない。
**データ**: 度数帯別の中央値（20〜26度:209円 / 36〜41度:330円 / 41〜46度:516円 / 60度超:113円）。
**紹介**: 高濃度スピリッツ（96度スピリタス、77度、75.5度）。
**注意**: 高濃度は割って飲む前提であることを明記する。

## 第2期（9〜16週目）— 横断的な発見

### 09. 単価を決めているのは種別ではなく容量だった
**主張**: 容量と単価の相関は −0.391。300ml以下767円に対し1.8L以上85円で9倍差。種別間の5.2倍より効いている。
**データ**: 容量帯別中央値、相関係数。
**注意**: note第1回で触れた話なので、銘柄単位の比較まで踏み込んで別記事にする。

### 10. 同じ銘柄でも容量違いで10倍ちがう — アブソルートの場合
**主張**: アブソルート ウォッカは750mlで185円、50mlミニチュアで1,949円。**10.5倍**。同一銘柄・同一中身で。
**データ**: 銘柄名でグルーピングし、容量違いの単価差が大きい13件。
**紹介**: 差が大きい銘柄を3〜4件。

### 11. セット買いは本当に得か — 単品との中央値比較
**主張**: セット品の中央値199円に対し単品410円。**51.5%安い**。ただし置き場所と消費期限は別問題。
**データ**: setCount>1 と =1 の中央値比較、度数帯を揃えた比較。

### 12. 楽天のポイント倍率は実際どのくらい付いているのか
**主張**: 2,466件中302件（12.2%）に期間限定倍率。4倍が266件と突出、10倍も3件。**24時間以内に終了するものはAPIに出ない**ので、この数字自体が瞬間の記録。
**データ**: pointRate の分布。
**サイト導線**: 還元率スライダーで順位が入れ替わる話に直結する。最も導線が効く記事。

### 13. 「送料別」表示の3割は当てにならない
**主張**: 送料別フラグが立つ1,846件のうち99件（5.4%）は商品名に「送料無料」と書いてある。フラグを鵜呑みにすると嘘になる。
**データ**: postageFlag と商品名の突き合わせ。
**注意**: 楽天やショップを非難する記事にしない。データの読み方の話に留める。

### 14. 1杯いくらか — 純アルコール20gを身近な単位に置き換える
**主張**: ハイボール1杯、水割り1杯、ロック1杯が実際いくらか。20g単価から逆算する。
**データ**: 代表銘柄の単価 × 一般的な1杯あたりの使用量。
**注意**: 使用量は一般的な目安であることを明記。厚労省のガイドラインに触れる。

### 15. 高評価かつ中央値以下の商品は、種別ごとに何本あるか
**主張**: ウイスキー86本、焼酎64本、ジン49本、ラム35本、ブランデー33本、ウォッカ25本、テキーラ9本。「安くて評価が高い」は珍しくない。
**データ**: 評価4.5以上・レビュー10件以上・中央値以下の件数。
**紹介**: 各種別から1本ずつ、計7本。

### 16. 最高額198万円から最安55円まで — 単価が3,500倍ちがう世界
**主張**: 掲載2,466件の幅。最高度数96度、最大20L、最小40ml、最多レビュー4,641件。
**紹介**: 極端な商品を並べる読み物。買わせる記事ではなく回遊させる記事。

**データ**: 初回と最新スナップショットの price 差分。

**主張**: 期間限定倍率は24時間単位で変わる。定点観測すると「いつ、どの商品が、何倍になったか」が見える。

**データ**: 各スナップショットの種別別中央値を時系列で。

### 21〜24. 未定（データを見て決める）

## 運用の型

**私（Claude）がやること**
- ネタの選定と執筆（この在庫から順に）
- 数字の実データ照合（記事の全数値を `data/items.json` と突き合わせる）
- ハッシュタグ選定、募集中のお題の確認
- 交流すべきクリエイターの抽出

**あなたがやること（週5時間）**
- 投稿（1本10分）
- **交流（スキ・フォロー・コメント）← 5時間の大半をここへ**
- 判断と最終確認

**自動化しないこと**
noteは自動化ツールに極めて厳格で、予告なくアカウントを止める。
フォローだけで削除された報告がある。楽天ROOMと同じで、
**判断は自動化してよいが、行為は人がやる**。

## 毎回の手順

1. `npm run update`（取得 → 解析 → 生成 → スナップショット保存）
2. 記事の数値を最新データで検算
3. 投稿
4. 3日後にビュー数とタグ別流入を確認 → 次回のタグ選定に反映
